## 改了什麼

截至台北時間 2026-11-11 11:35，npm 的穩定版 `latest` 指向 `0.167.1`，發佈時間是 2026-11-10 21:39:51 UTC，仍在 24 小時內。（官方套件資料：[npm metadata](https://registry.npmjs.org/@openai%2Fcodex)）

| 項目 | 一句話 |
| --- | --- |
| `0.167.1` | 官方更新紀錄列出這個版本，但內容只有與 `0.167.0` 的比較連結，沒有逐項修正說明 |
| `0.167.0` 的終端操作 | 官方記載 `Ctrl+L` 清除畫面後，仍能用 `Ctrl+T` 查看先前訊息 |
| `0.167.0` 的審批畫面 | 官方記載等待批准時能在對話內展開 patch 細節 |

以上兩項操作改善屬於 `0.167.0`。來源是[官方更新紀錄](https://learn.chatgpt.com/docs/changelog)，這篇沒有做本機行為實測。

## 為什麼要改

`0.167.1` 的摘要沒有說明修補原因，單看版號不能推定它修了哪些問題。

前一版記載的改善比較具體：清畫面後還找得到對話，批准修改前也能直接看 patch。我的判讀是，這兩項都減少了在終端裡來回找資訊的步驟。

## 對你的流程有什麼影響

1. 先跑 `codex --version`，記下本機版本。這篇的發佈判定只涵蓋 CLI，App 與 IDE 要各自查更新紀錄。
2. 若你用 npm 管理安裝，而且要切到這個已查證的版本，執行 `npm install -g @openai/codex@0.167.1`，完成後再確認版本。
3. 升級後，用 `Ctrl+L`、`Ctrl+T` 檢查自己的終端操作是否符合官方描述；遇到修改審批時，先展開 patch 再決定。這是建議的驗收步驟，不是本篇已測通的結果。
4. `0.167.1` 沒有逐項說明的修正先不用管。若你正追一個特定錯誤，確認對應變更後再判定是否已修好。
